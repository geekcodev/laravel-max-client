## Проблема

Ядро `max-php-client` перешло на v2.0.0: `Update` стал типизированной иерархией, enum `UpdateType`/`AttachmentType`
удалены, `getUpdates()` возвращает `UpdateList`, методы переименованы. Адаптер был написан под плоскую модель v1.1.11:
после подключения ветки ядра `new` падали 382 теста из 382.

## Решение

- `composer.json`: path-repository на `../max-php-client` и `dev-new as 2.0.0` (временно, до выпуска ядра).
- Новый `src/Support/UpdateInfo.php` — извлекает `chat_id`, `user`, `user_id`, `chat_type`, `is_channel` из любого
  типизированного апдейта; неизвестный подтип даёт пустой контекст, а не исключение.
- `PersistMaxChatListener` — ветвление по подтипам вместо `update_type`: активность (`message_created`/`edited`,
  `message_callback`, `comment_created`/`edited`), `chat_title_changed`, lifecycle `bot_*`. Поведение реестра сохранено.
- `PersistMaxUserPhoneListener` и `MaxContactService` — `ContactAttachment`, номер только из `vcf_info`
  (`vcfPhone` в ядре удалён), лог через `UpdateInfo`.
- `HandleMaxUpdateJob` — контекст лога из `UpdateInfo`; `MaxListenCommand` — `UpdateList::$updates`.
- `Config::DEFAULT_WEBHOOK_UPDATE_TYPES` — строковые значения.
- `Facades/Max.php` — PHPDoc пересобран под `ApiClient` v2 (guard-тест `MaxFacadeTest`).
- Примеры (`basic-usage.php`, `webhook-listener.php`) переведены на `sendChatAction`, `answerCallback` и typed-апдейты.

## Тесты

PHPUnit 371/371 (940 assertions). Удалены сценарии, невозможные в типизированной модели (lifecycle без `user` или без
`chat_id`): такие payload теперь отклоняются разбором, на это добавлен отдельный тест. Фабрики апдейтов переписаны на
подтипы.

## Нюансы

- Path-repository нужен только на время проверки: в релизный `composer.json` уйдёт `^2.0` без него.
- Публичный API пакета не менялся: конфиг, миграции, команды, middleware и событие `MaxUpdateReceived` прежние.
- `symfony/*` и `laravel/framework` обновлены до версий без advisory (10 → 0).
- Read-only смоук пройден; серверная проверка вебхуков в тестовом проекте ещё не пройдена — релиз ядра v2.0.0 и адаптера
  отложен.
