# Синхронизация адаптера с ядром v1.1.6

## Проблема

Constraint ядра `^1.1.0` при установленном v1.1.3; PHPDoc фасада отставал от `ApiClient` v1.1.6. События комментариев
(`Update::$comment`) реестр чатов не использовал.

## Решение

- `composer.json` → `^1.1.6`, `composer update` поставил v1.1.6 (`composer.lock` локальный, в Git не попадает).
- `src/Facades/Max.php`: +Comments API (5 методов), +`getUpdatesBatch`, `uploadMedia` → `UploadedInfo`,
  `sendAnswer` с `notification`/`disableLinkPreview`, пометки deprecated для `getChats`/`addChatMembers`
  (удаление в ядре v2.0.0).
- `src/Listeners/PersistMaxChatListener.php`: comment-апдейты дозаполняют `chat_type` из
  `CommentMessage::$recipient->chatType`, не меняя статус и не создавая чат.
- `tests/Unit/MaxFacadeTest.php`: guard-тест фасад ↔ ядро (все публичные нестатические методы `ApiClient`
  задокументированы с совпадающим типом возврата) — ловит такое расхождение, как найденное сейчас.
- `tests/Unit/Listeners/PersistMaxChatListenerTest.php`: 3 теста на comment-апдейты.
- `AGENTS.md`, `README.md`, `.agents/upgrade/UPGRADE_PLAN.md`: constraint `^1.1.6`, факты Comments API и
  `getUpdatesBatch`, отсылка к guard-тесту. План — `.agents/plans/2026-09-28-core-v1.1.6-sync.md`.

## Тесты

- `vendor/bin/phpunit --filter "MaxFacadeTest|PersistMaxChatListenerTest"` — 43 теста, 84 проверки, OK.
- Полный набор — 196 тестов, 463 проверки, OK; покрытие строк 98.20% (655/667).

## Нюансы

- Набор update types в `MaxSubscribeCommand` намеренно не расширен: это изменение поведения и трафика. Новые типы
  (`comment_*`, `bot_admin_permissions_changed`) приложение подписывает само через
  `createSubscription`.
- Reflection-нюанс теста: `(string) $reflectionReturnType` теряет ведущий `?`, поэтому nullability берётся из
  `allowsNull()`; статический `ApiClient::create()` и `__construct` исключены (фасад — прокси инстанс-методов).
- В рабочем дереве есть чужие незакоммиченные изменения (переименование `MaxChat`-регистра и правки
  `MaxWebhookController` с тестом) — не относятся к этой сессии и не коммитились.
