# Журнал сессий laravel-max-client

Карта сессий одной таблицей: одна строка на сессию, самые новые сверху. Подробности — в файле сессии
`sessions/<дата>-<тема>.md` (колонка `Файл`). Каталог `.agents/` отслеживается git: после `git clone` история разработки
доступна и человеку, и ИИ-агенту. Для внешних потребителей истина — `README.md`, `docs/api-reference.md` ядра и GitHub
Release; значимое из журнала дублируется туда. Формат и правила ведения — `AGENTS.md`, раздел 4.1. Секреты, токены,
`vcf_info`, телефоны и payload колбэков в журнал не пишутся.

(`git log --date=short --pretty=format:'%ad|%h|%s'`), сводка — в таблице выше, подробные описания релизов — в
`.agents/release/`. Новые сессии фиксируются по правилам раздела 4.1 `AGENTS.md`, старые записи журнала не удаляются.
